How it works
  1. Select topics in the popup and tap Broadcast.
  2. HeadlineFM checks 3 caches: local → shared backend → live Gemini call.
  3. The first user of the day triggers the AI narration — everyone else gets it instantly from cache.
  4. Google Gemini 2.5 Flash rewrites headlines into a fun, punchy script.
  5. The script is read aloud via the Gemini TTS API using fixed voices (Aoede / Charon).
  6. Results expire after 24 hours — fresh content every day.
