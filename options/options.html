▸ HOW IT WORKS
  1. Select news categories in the popup.
  2. Click BROADCAST — 3-tier cache check: local → shared backend → live Gemini call.
  3. The first user of the day triggers a Gemini narration. Everyone after gets it instantly from cache.
  4. Google Gemini rewrites headlines into a fun, punchy narration script.
  5. The script is read aloud using your browser's built-in speech engine.
  6. Results are cached locally per day — no wasted API calls on repeat opens.
